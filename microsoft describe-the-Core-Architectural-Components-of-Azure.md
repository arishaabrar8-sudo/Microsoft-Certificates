## 📖 Overview
This module introduced the fundamental architectural components of Microsoft Azure. It explained how Azure is organized globally and how resources are managed to build secure, scalable, and highly available cloud solutions.

## 🎯 Key Concepts Learned

### 1. Azure Regions
- Geographic locations containing one or more datacenters.
- Allow applications to be deployed close to users for lower latency.

### 2. Availability Zones
- Physically separate datacenters within an Azure region.
- Improve application availability and fault tolerance.

### 3. Region Pairs
- Two Azure regions are paired for disaster recovery.
- Help ensure business continuity during outages.

### 4. Azure Resources
- Individual services such as Virtual Machines, Storage Accounts, and Databases.

### 5. Resource Groups
- Logical containers used to organize and manage Azure resources.

### 6. Azure Subscriptions
- Used for billing, access control, and resource management.

### 7. Management Groups
- Organize multiple Azure subscriptions under a single hierarchy.
- Simplify governance and policy management.
